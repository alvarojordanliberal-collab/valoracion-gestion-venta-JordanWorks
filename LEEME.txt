JORDAN WORKS — SISTEMA DE REPUTACIÓN V2

Archivos:
- index.html: página pública de experiencias.
- admin.html: panel para añadir testimonios.
- reviews.json: base de datos de testimonios.

Cómo usarlo:
1. Sube los tres archivos al mismo repositorio de GitHub Pages.
2. Abre /admin.html para gestionar testimonios.
3. Añade una respuesta real.
4. Pulsa "Descargar reviews.json".
5. En GitHub sustituye el reviews.json antiguo por el nuevo.
6. La página pública /index.html se actualiza automáticamente.

IMPORTANTE:
GitHub Pages es alojamiento estático. El panel no puede escribir directamente en GitHub por sí solo de forma segura. Por eso el flujo actual es: añadir -> descargar JSON -> subir JSON a GitHub.
La siguiente evolución, si quieres, es conectar esto con Google Sheets/App Script para que las respuestas se guarden automáticamente y no tengas que subir el JSON manualmente.
